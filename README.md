# Miu Tea — магазин чая

Небольшой адаптивный сайт магазина чая в минималистичном стиле с мягкими природными оттенками и котиками.

## Функции
- Каталог из трёх видов чая.
- Добавление товаров в корзину с обновлением счётчика.
- Сообщение о содержимом корзины.
- Адаптивная вёрстка для телефона и компьютера.

## Запуск
Откройте `index.html` в браузере.

## Автоматическая проверка
GitHub Actions запускает Workflow при каждом `push` в ветку `main`. Он проверяет наличие `index.html`, `style.css`, `script.js`, устанавливает Node.js-зависимости и запускает ESLint.

Локальная проверка:
```bash
npm install
npm run lint
```
